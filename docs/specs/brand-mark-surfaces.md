# Nex N 图标在应用内的展示

## 产品规则与所有者

- 七处现有图标使用同一套 folded-ribbon N 三笔路径，只替换字形，所有应用与安装素材统一黑白灰，不再使用薄荷绿。
- `packages/ui` 负责共享 React 空态、启动徽标与 About；Web 与 Desktop 各自负责 JS 加载前的 HTML splash，Desktop main 负责原生 About HTML。保持当前依赖方向，不为静态品牌资源引入运行时跨包加载。
- 三笔路径沿用 1024 坐标系，字形裁剪框为 `258 255 510 516`。单色/轮廓场景均不变形；各处复制的路径通过一致性测试防止漂移。

## 展示接口与不变量

| 场景                        | 展示规则                                                                                                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 深色对话空态 `assets/N.svg` | 透明、无底板；还原旧 `Z.svg` 的灰色渐变：`#444444`/0.6 → `#2A2A2A`/0.3 → `#1A1A1A`/0.1；填充层 opacity 0.15、Gaussian blur 1.2px、1px 描边。N 等比映射到旧 436×360 画布内，保留上下约 20px 留白。 |
| 浅色对话空态                | 同形 N、currentColor 轮廓，保留现有 opacity 0.7 和向下 mask 渐隐；不叠加深色 SVG 的效果。                                                                                                         |
| Web / Desktop About         | 同形白色 currentColor N，宽 30px、高度自适应，放入现有 52px 深色图标容器，不溢出、不含 mint 渐变。                                                                                                |
| Web HTML splash             | 同形白色 N，保留三笔 opacity 轮闪与现有 96px 底板、56px 图标宽度。                                                                                                                                |
| Desktop HTML splash         | 同形白色 N，保留壳层入场动画、减少动态效果偏好以及原来的启动移除逻辑。                                                                                                                            |
| React Root loading          | 同形白色 N，保留 busy/label 语义、可选呼吸动效以及当前尺寸。                                                                                                                                      |

## 边界与失败语义

本次只修改静态视觉，不变更主题状态所有者、时序、启动事件或接口。
现有主题类选择深浅空态；深色资源通过本地打包的 img URL 加载，不增加网络请求、回退资源或计时器。
应用/安装素材与公共副本都使用同一黑白 N；运行时引用路径和打包配置保持不变。

## 验收

1. 深色桌面与手机宽度下，空态 N 是低对比灰色水印，无绿色、无圆角块，不遮挡问候语。
2. 浅色空态保留线框渐隐，切换主题时两版本互斥。
3. 两种 About 的 N 外形一致、呈白色，均在 52px 容器内按 30px 宽度居中。
4. 七处 SVG 的三笔 N 轮廓一致，渐变与 viewBox 不裁切笔画；启动动画行为保持原样。
5. 实际渲染深浅空态及启动/About 图标，检查尺寸、颜色与手机宽度；运行品牌资源回归测试、typecheck、lint 和架构检查。

## 设置页「帮助 → 关于」（2026-10-18）

### 产品规则与接口

- 设置导航依次展示「基础设置」「Agent 能力」「数据与统计」「帮助」分组；「关于」归属最后的「帮助」分组，使用与其他分组相同的标题、间距和 `SettingsSidebarButton` 样式，不再单独用横线分隔一个操作按钮。
- 「关于」是正式的 `about` 设置分区。点击后在设置页右侧平铺展示，不弹窗、不显示遮罩或确认按钮；Desktop 与 Web 均可使用，不依赖是否打开会话。
- 平铺内容显示端对应的应用名、构建期 `NEX_VERSION`、完整 `NEX_COMMIT`、版权及原有平台条件下的 Apple Silicon 提示。Commit 默认可见、可选择并允许长内容换行，不需要展开。
- 复用 `WorkspaceAboutDialog.tsx` 内的白色 N 与 52px 深色品牌图标；内容使用设置页统一列宽、主题色和 `text-ui-*` 字号，不复制弹窗的小尺寸排版。
- 工作区帮助菜单的 `AboutDialog` 和 Desktop main 的原生关于入口保持现有行为及样式；不恢复已移除的设置页帮助按钮。
- `SettingsPage.activeSection` 是当前设置分区的唯一所有者；沿用现有导航回调和分区偏好机制识别、保存及恢复 `about`。删除设置专属的弹窗开关状态，不新增服务、网络请求、平台命令或业务持久化字段。

事件顺序：

```text
点击「帮助 → 关于」 → SettingsPage.activeSection = about
                            ├→ 现有导航偏好保存 about
                            └→ AboutSection 平铺读取构建期版本与 Commit
点击其他分区 → 同一路径切换内容；重新进入设置 → 现有偏好恢复 about
```

### 验收场景

1. Web 未打开会话时进入设置，左侧「数据与统计」之后出现「帮助」分组，只有一个「关于」菜单项；宽屏无独立横线按钮，窄屏沿用其他分组的 icon rail 规则。
2. 点击 `settings-section-nav-about`，设置页 `data-active-section` 为 `about`，右侧显示 `settings-about-section`，菜单有选中态及 `aria-current=page`，不出现 `workspace-about-dialog`。
3. 页面立即显示应用名、当前构建的版本与完整 Commit；无详情开关、确定按钮或关闭交互。长 Commit 在手机宽度下换行，不横向撑破布局。
4. Apple Silicon 提示保持已有桌面 macOS 条件，Web 不展示；版权、N 图标和浅色/深色主题、中英文均保持一致。
5. 切换其他设置分区正常；停留「关于」后退出并重新进入设置，沿用既有偏好恢复该页。一次性导航意图 `about` 同样可被识别。
6. 原工作区关于弹窗仍可打开和展开 Commit，原生关于入口不受影响。回归测试覆盖帮助分组配置、about 导航识别、平铺版本与 Commit、无设置专属弹窗状态和品牌图标复用。
7. 本次按要求不在本机运行测试、构建或验证命令；以上交互场景交由部署环境验收。

## 应用与安装资源（2026-10-07）

- `public/logo/icon.svg` 是应用图标的矢量源：1024×1024、黑色渐变圆角底板、同一组三笔白色 N，透明外边距不少于 100px。不使用绿色渐变。
- Desktop build 的应用/Windows/安装 PNG、ICO、ICNS、Linux 多尺寸 PNG，及 `public/logo/icons` 副本从该源导出；保持现有文件名、尺寸、透明度和运行时路径。
- `public/icon_512@2x.png` 更新为同一 1024×1024 N，修复更新弹窗继续展示旧 Z 的不一致。
- Web `index.html` 内嵌 32px favicon 与公共 32px PNG 一致；`packages/web/public/favicon.ico` 使用同一新 N，保证显式图标与默认 favicon 路径一致。
- DMG 背景保留布局、指引文字和安装区域，将绿色折叠装饰改为灰白，标题图标使用黑底白色 N。1× 为 540×380/72dpi，2× 为 1080×760/144dpi。
- 静态素材由所属包打包，公共目录保留品牌源与副本；本次不修改窗口/托盘、更新流程与启动事件的状态所有者。
- 验收：所有资源可解码、各帧尺寸符合格式；PNG/ICO/ICNS 中可见像素中性灰（RGB 通道差不超过 1）；各副本对应一致；1024 图标外边距完全透明；旧 Z 消失；DMG 的 Applications 拖入位置不被装饰占用。核对浏览器标签页与各平台图标的素材预览。
